Les menus, puis les courses

La liste de courses se compose toute seule.

Choisissez les plats de la semaine : les ingrédients se rassemblent, les quantités s'additionnent, et la liste se range dans l'ordre du magasin.

Une seule ligne par produit

Trois recettes qui demandent des oignons ne font pas trois lignes. Les grammes s'additionnent entre eux, les pièces entre elles.

Rangée comme le magasin
